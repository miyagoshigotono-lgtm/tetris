# ブロックおとし

マイクラ風のブロックが落ちてくるテトリス風ゲーム。広告なし・データ送信なし。

**あそぶ:** https://miyagoshigotono-lgtm.github.io/tetris/

## ルール

- 基本はテトリス（10×20、7 種のブロック、ライン消去、10 ラインごとにレベルアップ）
- だいたい 20 回に 1 回、**TNT（1 マス）** が落ちてくる
- **火打ち石ボタン**で、置いてある TNT を全部爆発させる
  - 爆風は周り 3×3。壊したブロック 1 個 = 10 点 × レベル
  - 爆風が当たった列は、浮いたブロックが下に落ちる
  - 落ちてそろったラインは得点 2 倍
- ライン消去では TNT は消えずに残る（TNT の上のブロックも支えられて残る。TNT だけの行は消えない）
- 段消しで下がってまたそろった行は続けて消える

## そうさ

| ボタン | キーボード |
|---|---|
| ← → | ← → |
| ↓（ゆっくり） | ↓ |
| ⟳（回転） | ↑ / X（Z で逆回転） |
| ⤓（一気に落とす） | スペース |
| 火打ち石 | F / Enter |
| ポーズ | P / Esc |
| BGM のオン・オフ（音符ボタン） | M |

## ホーム画面に置く

- **iPhone**: Safari で開く → 共有ボタン → 「ホーム画面に追加」
- **Android**: Chrome で開く → メニュー → 「ホーム画面に追加」（または「アプリをインストール」）

全画面で動き、オフラインでも遊べる。

## 音

- 効果音とピアノの BGM（どちらもコードで合成したオリジナル）
- スピーカーボタンで効果音、音符ボタンで BGM をオン・オフ
- iPhone（iOS 17 以降）はマナーモードでも鳴る。鳴らしている間は他のアプリの音楽が止まる

## 更新のしかた

1. 変更を PR にして `main` にマージする
2. GitHub Pages が 1〜2 分で反映する（URL は変わらない）
3. 遊ぶ側はアプリを開き直すだけ。Service Worker がネット優先なので、つながっていれば必ず最新版になる

タイトル画面右下のバージョン（`js/main.js` の `VERSION`）を上げておくと、更新が届いたか確認しやすい。

## 構成

```
index.html / style.css   画面
js/logic.js              ルール本体（DOM なし・テスト対象）
js/main.js               描画・操作・演出
js/textures.js           ブロックのドット絵（コードで生成）
js/icons.js              ボタンのドット絵
js/audio.js              効果音（Web Audio で合成）
sw.js                    オフライン対応（ネット優先キャッシュ）
tools/make-icons.js      PWA アイコン生成（npm run icons）
tests/                   ルールのテスト（npm test）
```

ビルド不要。Node.js 22 があれば `npm test` でテストが走る。手元で動かすなら `python3 -m http.server` などでフォルダを配信して開く。

ブロックの絵はすべてこのリポジトリのコードで描いたオリジナル。Minecraft の素材・名称は使っていない。
